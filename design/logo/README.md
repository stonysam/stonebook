# Stonebook logo

Stone cottage line drawing, red roof, chimney, one heart-shaped stone (version B, chosen 19 Oct 2026).

- `cottage.py` draws the variants (`python3 cottage.py <outdir>`); `cottage-b-bold.svg` is the chosen one.
- `icon.svg`, `maskable.svg`, `apple-touch.svg`, `badge.svg` are the sources for `public/icons/*.png` and `app/icon.png`.
